**Campaign setup:** This is marketing content. Use a Brevo *email campaign*, not the transactional password-reset endpoint. Import only the CSV from the admin **Product email audience** card into a dedicated opted-in list. Include Brevo's unsubscribe link in the footer and follow its suppression and unsubscribe handling. Check sender identity and both links, send a preview, then schedule or send the campaign in Brevo. Export immediately before the send and replace the list so preference changes are respected. Existing users are not included until they explicitly enable **Product emails** in their dashboard; new users must check the optional box at signup. Do not bulk-email the general admin user list.
